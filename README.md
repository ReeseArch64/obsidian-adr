# Obsidian ADR

Skill para registrar e manter decisões arquiteturais em um vault Obsidian. Inclui modelos Markdown para decisões diretas e comparativas, exemplos e orientações para manter índices, identificadores e vínculos entre decisões.

## Instalação

Execute na raiz do vault e selecione `obsidian-adr` e seu agente.

```sh
npx skills add ReeseArch64/obsidian-adr
```

## Uso

Peça ao agente para consultar decisões existentes, redigir um ADR sobre uma escolha confirmada ou atualizar um registro após uma substituição. A skill segue as convenções do vault e inclui orientações para coleções com categorias em `08-Decisions/00-ADRs/`.
